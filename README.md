# Finance Tracker App 💰

A full-stack finance tracker application for managing income and expenses, calculating balances, and organizing financial transactions with a clean and user-friendly interface.

---

## 📱 Features
- User authentication (Login & Signup)
- Add income and expenses
- Categorize transactions
- View total balance
- Secure data storage
- Simple and intuitive UI

---

## 🛠 Technologies Used
- Frontend: React Native (Expo)
- Backend: Supabase
- Database: PostgreSQL
- Authentication: Supabase Auth
- Version Control: Git & GitHub

---

## 🚀 Getting Started

### Prerequisites
- Node.js installed
- Expo CLI
- Git

### Installation
```bash
git clone https://github.com/nasiramme1511/finance_tracker.git
cd finance_tracker
npm install
npx expo start
